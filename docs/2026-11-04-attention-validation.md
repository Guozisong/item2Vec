# 注意力 Item2Vec 实现与本地验证

分支：feature/attention-item2vec。基于e073271构建。

## 实现范围

- attention训练器：完整购物篮去掉目标后编码；一层无位置编码自注意力、有效位置平均池化；共享商品向量参与上下文预测和商品对余弦对比目标。
- 每轮完整覆盖各篮的全部目标，混合完整及随机非空上下文；随机负样本排除整篮，分布仅使用最终训练频次。
- 支持CPU/CUDA选择、配置预检、逐轮验证、早停和最佳模型保存。导出归一化商品向量及所选模型的完整状态；支持重新加载完整状态，CLI不提供断点续训。
- 训练、查询、批量导出、流水线均已接入；cosine元数据显式选择同空间余弦，行为迁移和文本回退保留，旧模型维持原打分方式。
- 原研究工作树的9个未提交文件未合入；此前用户停止的真实数据训练未恢复。

新增验证覆盖：目标在编码前移除、每轮目标完整性、整篮负样本排除、置换与padding不变性、单商品上下文、两项损失更新共享向量、配置非法组合预检、最佳轮次而非最后一轮导出、冷商品零向量、checkpoint恢复与导出一致、原始余弦查询/导出、冷启动迁移归一化、旧模型兼容，以及真实Bash入口的端到端执行。

代码审阅发现一个性能问题：每处理256个篮重新计算全部篮大小，导致额外的二次扫描。新增回归测试确认1024个篮触发4次全量扫描后，改为每轮缓存一次；复审确认修复，无剩余重要问题。

## 独立合成数据验证

目录：outputs/attention-smoke-20261104；日志：outputs/attention-smoke-run.log。

80张订单，两个互不共购的三商品组，6个训练商品、1个无行为商品。使用16维、4头、负样本5、30轮、CPU、种子17；这是有界合成验证，不是真实数据后台实验。

| 指标 | 结果 |
| --- | ---: |
| 共购组内平均余弦 | 0.85105449 |
| 组间平均余弦 | -0.83559740 |
| 有行为商品向量范数 | 约1 |
| 无行为商品向量 | 全0 |

商品000的Top2为001、002，余弦分别为0.899709和0.866961。无行为商品006成功通过behavior_transfer召回；完整批量导出14条。完整数值和来源见该目录smoke_report.json。

## 验证边界

实际运行环境为Python3.13.5、PyTorch2.14.0、NumPy2.3.3。仅验证本机CPU路径；CUDA、DLC环境及真实数据召回提升尚未验证。合成数据结果只证明模型能够学习已知分组关系及训练到召回链路一致，不说明注意力优于原模型。原tune_item2vec.py的实验矩阵尚未包含attention，真实对照需独立输出目录和固定留出切分。

设计：[整篮注意力与商品余弦联合训练](superpowers/specs/2026-11-04-attention-item2vec-design.md)。使用方式见README的注意力训练器段落。

# 注意力 Item2Vec 实现与本地验证

分支：feature/attention-item2vec。以下430项测试和合成数据结果为2026-11-04实现时的历史记录。当前分支已收敛为仅attention训练，最新检查结果见文末。

## 实现范围

- attention训练器：完整购物篮去掉目标后编码；一层无位置编码自注意力、有效位置平均池化；共享商品向量参与上下文预测和商品对余弦对比目标。
- 每轮完整覆盖各篮的全部目标，混合完整及随机非空上下文；随机负样本排除整篮，分布仅使用最终训练频次。
- 支持CPU/CUDA选择、配置预检、逐轮验证、早停和最佳模型保存。导出归一化商品向量及所选模型的完整状态；支持重新加载完整状态，CLI不提供断点续训。
- 训练、查询、批量导出、流水线均已接入；cosine元数据显式选择同空间余弦，行为迁移和文本回退保留。
- 原研究工作树的9个未提交文件未合入；此前用户停止的真实数据训练未恢复。

## 验证边界

实际运行环境为Python3.13.5、PyTorch2.14.0、NumPy2.3.3。仅验证本机CPU路径；CUDA、DLC环境及真实数据召回提升尚未验证。合成数据结果只证明模型能够学习已知分组关系及训练到召回链路一致，不说明注意力优于原模型。真实数据验证需独立输出目录和固定留出切分。

设计：[整篮注意力与商品余弦联合训练](superpowers/specs/2026-11-04-attention-item2vec-design.md)。使用方式见[README](../README.md)。

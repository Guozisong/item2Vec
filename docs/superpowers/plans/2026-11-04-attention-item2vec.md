# Attention Item2Vec 实现范围

当前分支仅支持attention训练，不包含其他训练器和自动对照实验入口。

- [x] 模型：共享商品向量表、单层多头自注意力、整篮上下文与商品对余弦联合损失。
- [x] 样本：逐个移除目标，覆盖篮内全部目标；完整及随机非空上下文，负样本排除整篮。
- [x] 训练：默认attention，CPU/CUDA、参数预检、逐轮验证、早停和最佳轮次保存。
- [x] 推断：只加载注意力余弦产物，保留行为迁移、文本回退、单商品查询和批量导出。
- [x] 清理：删除旧训练器、旧候选偏置、专用调参脚本及对应依赖、测试和使用说明。

验证记录见[本地验证](../../2026-11-04-attention-validation.md)。真实数据效果和CUDA需单独验证；本次不启动真实数据后台训练。

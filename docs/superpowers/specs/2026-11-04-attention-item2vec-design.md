# 整篮上下文与注意力 Item2Vec 设计

状态：已在feature/attention-item2vec分支实现。此前后台训练保持用户要求的停止状态；本次只进行CPU合成数据验证。

## 目标与边界

使用订单购物篮训练商品行为向量；同单关联通过神经网络目标学习，不使用共购统计分数进行召回排序。每个有行为的商品最终导出一个固定、L2归一化的向量，单商品查询按同一空间中的余弦相似度取TopK。

注意力用于训练时整合篮内上下文。上下文预测效果提升不自动等于单商品余弦召回提升，因此同时直接训练最终导出的商品向量。余弦作为关联排序分数，不解释为经过校准的共现概率；不承诺所有共购对都能满足严格单调排序。

本分支仅提供attention训练器，训练、验证和推断统一使用共享商品向量余弦。

## 方案比较

1. 平均池化CBOW：整合多个上下文商品，结构最简单，作为联合上下文基线。
2. 仅注意力上下文预测：能学习上下文关系，但没有直接约束导出向量之间的余弦，仅作消融对照。
3. 注意力上下文预测加商品对余弦目标：两条训练分支共享商品向量，作为建议主方案。

## 训练样本

沿用合格购物篮的去重和过滤规则，不引入商品文本作为行为训练输入。对于篮B的每个目标t，输入C=B去掉t，目标t在进入编码器前移除；不能先编码完整篮后再遮住目标，以免通过自注意力泄漏答案。

默认遍历每个目标，一张n件商品的篮得到n个上下文预测样本。负样本从最终训练商品词表按训练频次的0.5次幂抽取，排除当前整篮商品。使用随机负样本。

上下文包含完整C及随机非空子集两种训练视图，随机子集大小在1到上下文大小间均匀抽取，覆盖单商品上下文。完整视图与子集视图的损失取平均，不因额外视图将订单权重翻倍。

各目标样本等权；每篮生成n个目标样本，商品对损失在每个目标的正上下文内取平均。

## 结构

共享商品向量表E，每个商品用于召回的向量为z_i=normalize(E_i)。

上下文分支：

```text
上下文商品ID（不含目标）
  -> 共享向量表E
  -> 一层多头自注意力编码块（含残差、前馈和归一化）
  -> 对有效商品做平均池化
  -> L2归一化，得到上下文向量h_C
  -> 与目标及负样本的z向量计算余弦分数
```

不使用商品索引位置编码；注意力屏蔽padding，池化排除padding。这样同一上下文交换商品位置不改变确定性推断结果。仅使用不依赖其他商品的逐商品权重不能充分建模上下文之间的交互，因此主方案采用自注意力后再池化。

商品对分支直接使用同一套z向量，对每个目标t及C中的商品i学习cos(z_t,z_i)，排除自配对。该分支在每个目标内对正上下文取平均，避免单条上下文样本随商品数量增加而改变两项损失的比例。

## 训练目标

上下文损失：在目标及抽取的负样本中，用h_C与各商品z的余弦除以温度tau，优化目标商品的交叉熵。

商品对损失：对C中的每个正商品i，用z_t与正商品及抽取负样本的余弦除以tau，优化正商品的交叉熵，再对i取平均。它直接约束导出商品向量的排序，避免只把上下文编码器训练好。

总损失为L_context + lambda * L_pair。初始验证配方设lambda=1，两项均采用每目标平均；仅上下文消融设lambda=0。温度为独立验证参数，用于调整余弦对比分数的尺度。

两条分支共享同一E，导出时不另外选择未被商品对损失约束的中间层或投影头。单商品上下文中注意力无法选择多个商品，单商品排序由共享向量与直接余弦目标训练，实际效果仍需验证。

## 导出与推断

归一化的z写入behavior_item.npz的vectors，未覆盖商品保留零向量；保留商品编码、订单数和完整训练元数据。

模型元数据显式标注behavior_score=cosine及trainer=attention。推断只接受匹配的注意力产物，统一使用共享向量余弦。

新模型纯行为路径使用cos(z_a,z_b)，候选为有行为向量的商品，排除自身。保留现有无行为商品的行为迁移、文本回退链；迁移向量需要归一化后再做余弦。文本融合另行显式设置，不用于证明行为训练收益。

注意力模块用于训练上下文任务，静态商品TopK导出不需要输入完整购物篮或逐候选执行注意力。

完整的所选模型状态另存attention_model.pt，含编码器、向量表及有效商品行映射；当前CLI不提供断点续训。注意力专属参数和使用命令见README。

## 验证与验收

可用pair-loss-weight=0与默认联合目标比较，检验商品对损失的作用。保持数据切分、参考商品集合和负样本设置一致，报告训练更新数、耗时与资源消耗。

主评估仍是单商品到其他共购商品的Top50，包括宏平均Recall、加权Recall、低频Recall、候选覆盖和曝光集中度；购物篮补全作为辅助指标。不能以补全任务提升替代单商品召回验收。

单元和集成验证需要覆盖：输入不含目标、整篮负样本排除、上下文置换不变、padding不影响结果、单商品上下文、两项损失确实更新共享向量、导出与训练使用同一余弦、非注意力产物拒绝，以及小型独立共购组能学习到组内高于组间的余弦。

真实数据先完成小规模验证，再决定是否开展全量训练。最终测试集仍在冻结配置后一次性评估；当前设计不授权自动恢复此前已停止的后台实验。
